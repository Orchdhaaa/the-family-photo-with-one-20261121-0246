A photorealistic candid family photograph: a family at home in the kitchen with one machine member, a small domestic robot caught mid-task peeling a carrot at the counter while the family cooks around it. The robot is a worn household machine that already lives there, not a prop. The entry is the single image `entry.png` (1024x1024 JPEG); `main.ts` copies it to the output directory (Node 22, stdlib only).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
